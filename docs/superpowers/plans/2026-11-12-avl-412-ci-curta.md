# AVL-412 — validação integral em jobs de até um minuto

> **For agentic workers:** executar com `superpowers:executing-plans` neste
> checkout, sem outros agentes ou worktrees, conforme autorização existente.

**Goal:** concluir a validação da entrega XML/SEFAZ respeitando o limite do
projeto: `timeout-minutes: 1` em cada job, sem retirar testes ou aceite.

**Architecture:** instalar dependências uma vez e reutilizar cache exato por
lock/schema. Construir standalone no runner; conferir também os tipos gerados
pelo Next em job separado; executar toda a suíte em shards independentes com
PostgreSQL. Somente então montar e testar a imagem de runtime.

**Tech Stack:** GitHub Actions, Node 22, Next 16, Prisma 7, PostgreSQL 18,
Vitest 3, Docker. Runners hospedados pelo GitHub; nenhum build local/servidor.

**Spec:** desenho XML/SEFAZ já aprovado e política do projeto TMS no Linear.
O pedido de continuação resolve a pendência pelo caminho que cumpre a política;
não representa aprovação da exceção de tempo.

## Global Constraints

- Todos os jobs têm `timeout-minutes: 1`, incluindo publicação/deploy.
- Preservar suíte, RLS, typecheck, construção e teste da imagem.
- Não acompanhar CI continuamente; consultas pontuais ligadas a entregas.
- PR não publica imagem; deploy permanece restrito à main e à variável atual.
- Sem merge, migração ou deploy em produção nesta tarefa.

## Review Focus

- Falha ou timeout de qualquer shard impede checks e publicação.
- Cache leva a versão correta do Prisma para o schema atual.
- Typecheck inclui os validadores gerados por este mesmo build Next.
- Standalone Linux funciona na imagem final, incluindo Sharp e Prisma/Postgres.
- Artefatos pertencem ao mesmo run/commit; PR não acessa publicação/deploy.
